# Security Policy

## Supported version

Security fixes are applied to the latest release line.

## Reporting a vulnerability

Please avoid posting credentials, private infrastructure details, sensitive logs, or exploit material in a public GitHub issue. Report security-sensitive defects privately to the repository owner through an appropriate private channel.

Include the affected version, component, reproduction conditions, expected behavior, actual behavior, and a minimal redacted proof of the issue.

## Authorized-use boundary

Hobbit-NG is intended for defensive assessment of systems the operator owns or is explicitly authorized to test. The project does not accept features whose primary purpose is credential theft, destructive exploitation, persistence, or unauthorized access.
